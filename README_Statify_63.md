# Statify: Pengembangan Angkatan 63

Dokumen ini merangkum kontributor dan modul yang dikembangkan oleh mahasiswa **Politeknik Statistika STIS angkatan 63**. Gambaran umum aplikasi, cara menjalankan, dan struktur repositori ada di [README.md](README.md). Lanjutan pengembangan oleh angkatan 64 ada di [README_Statify_64.md](README_Statify_64.md).

## Pengantar

Pada siklus pengembangan angkatan 63, Tim Statify mengembangkan enam modul secara paralel, yaitu modul manajemen data dan analisis deskriptif, uji statistik parametrik dan nonparametrik, grafik dan transformasi data, analisis time series, analisis regresi linier dan estimasi kurva, serta pemodelan linier dan klasifikasi data.

Pengembangan memakai metode Feature-Driven Development (FDD) dan dievaluasi dengan pengujian white-box dan/atau black-box serta kuesioner usabilitas SUMI. Seluruh modul digabung ke satu aplikasi Statify yang berjalan di browser. Judul skripsi masing-masing mengikuti pola "Pengembangan Statify: Aplikasi Analisis Statistik Modul ...".
